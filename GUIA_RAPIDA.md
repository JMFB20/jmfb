# Guía rápida: relay de Gazapo Link 0.8.0 — 4P EXP

Este paquete corresponde exclusivamente al **protocolo 10**.

## Método recomendado

Usa el botón **Deploy to Cloudflare** del README. No necesitas instalar programas
en la PC. Sí necesitas cuentas gratuitas de Cloudflare y GitHub.

Cuando el despliegue termine, copia la URL `.workers.dev` y guárdala en todos los
dispositivos desde `Gazapo Link > ⋯ > Servidor online`. Todos deben usar exactamente
la misma dirección.

Al abrir la URL en un navegador debe aparecer `"protocol":10`.

## Alternativa manual para Windows

Si descargaste este repositorio, instala Node.js LTS, descomprímelo y ejecuta
`CREAR_RELAY_WINDOWS.bat`. La computadora puede apagarse después del despliegue.
